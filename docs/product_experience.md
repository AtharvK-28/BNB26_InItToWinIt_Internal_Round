# Creator experience: a coordinated production workflow

Updated: 4 October 2026. Keep the established warm studio design and accessible controls. The current scope is multi-agent assistance with candidate review and export, not an embedded editor.

## Main flow

Material → Story → Cuts → Deliver remains the project navigation. Script-first and footage-first requests converge on the same project.

1. Add source footage and a brief, or supply an existing script.
2. Review the Story Agent's hooks/script; accept a draft explicitly.
3. Request clips. The coordinator gathers evidence through Research and asks Director to select moments.
4. Review a small candidate set with real playback, source range, story connection and uncertainty. Approve, reject or request a revision such as keeping the whole sentence or finding the actual demonstration.
5. Choose a platform preset and download the MP4 plus portable editable package.

Agents work behind one production request. The creator does not manage three chat windows, configure an agent swarm or read internal conversations. Useful progress can show which responsibility is active: drafting the story, gathering evidence, choosing cuts or preparing exports. Tool activity and source evidence are available on demand; model thoughts are not shown.

## Scope and polish

Do not design or expand an inbuilt timeline, multi-track editor or cover canvas. Existing experimental controls are outside required scope; removing/de-emphasizing them needs an implementation pass. Editable output is preserved in source-linked files for external use.

Use one strong next action per stage, a few candidates, and progressive disclosure for evidence and revision details. Include empty, uploading, missing-evidence, needs-review, rendering, quota-failed, cancelled and version-conflict states. Avoid invented analytics or false progress percentages.

Keep project state, candidate versions and creator decisions when navigating. Mobile supports preview/review/approval/download, without pretending to provide desktop precision editing. Controls retain 44px targets, semantic labels, keyboard focus, readable contrast and reduced-motion support.

Root DESIGN.md and the pinned OpenDesign/Hallmark/UI UX Pro Max resources remain the visual baseline; no new design system or paid editor tooling is required.
